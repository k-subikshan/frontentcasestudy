# NEXUS VPS Frontend Only

Open `index.html` directly in a modern browser. No backend, database, package installation, or local web server is required.

Demo login: `admin@nexusvps.dev` / `nexus-demo` (any valid email and non-empty password also work).

Pages: Overview, VPS Connections, Monitoring, Web Terminal, AI Assistant, Services & Logs, Settings.

Important: This is a static HTML/CSS/JavaScript prototype. Login is not real authentication. Server records, metrics, terminal output, logs, and assistant responses are illustrative only. It does not connect to a real VPS, execute shell commands, or call an AI service. Do not enter real passwords or secrets.
